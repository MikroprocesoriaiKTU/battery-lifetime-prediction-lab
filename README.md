# Battery Lifetime Prediction Laboratory

Teaching materials accompanying the paper *Teaching Embedded Systems Power Profiling through Battery Lifetime Prediction*.

Laboratory assignment developed for the course *Embedded Systems* (T170B417), Faculty of Electrical and Electronics Engineering, Kaunas University of Technology, Lithuania.

Repository: https://github.com/MikroprocesoriaiKTU/battery-lifetime-prediction-lab

## Contents

- `docs/Lab_handout_EN.pdf` — laboratory handout (English).
- `firmware/stm32l433/` — STM32L433 firmware template: CubeMX configuration, Keil MDK project, and the required vendor and library sources.
- `statechart/` — itemis CREATE statechart model, generator configuration, and generated C sources (open in itemis CREATE with *File → Import → Existing Projects into Workspace*).
- `hardware/` — schematic, bill of materials with supplier links, board variants, and assembly guide for the sensor/display add-on board. The add-on board is assembled from modules and through-hole components on an Arduino Uno prototype shield; it is not a custom PCB, so there are no PCB layout or Gerber files.

## Setup overview

The setup is a three-level stack: an X-NUCLEO-LPM01A power measurement board, a NUCLEO-L433RC-P target board, and the course-specific sensor/display add-on board. Students model the application as a state machine, measure the active and sleep durations of the firmware, predict the average current and battery lifetime with the STM32CubeMX Power Consumption Calculator, measure the current of the complete system, and explain the difference. See the handout in `docs/` and the assembly guide in `hardware/assembly/`.

## Building the firmware

Open `firmware/stm32l433/MDK-ARM/Lab2_DemoFirmware.uvprojx` in Keil MDK 5 (tested with Arm Compiler 6.16 and 6.24) and build. The CubeMX configuration was created with STM32CubeMX 6.12.0 and STM32Cube FW_L4 V1.18.2; itemis CREATE and STM32CubeMonitor-Power are used in their latest versions. The project takes the state-machine sources from `statechart/src` and `statechart/src-gen`; the Event Recorder configuration (`RTE/`) is regenerated by Keil with default settings. `CMSIS_device_header` is defined in the project's C preprocessor settings, because newer STM32L4xx device packs no longer add it to the generated `RTE_Components.h`.

The template is set to `-O0` (no optimization), the starting point of the compiler-optimization experiment. At `-O0` the image is about 35 KB, which exceeds the 32 KB code-size limit of the free MDK-Lite edition; use a full or MDK Community licence, or build with `-Os` (about 23 KB) on MDK-Lite.

`Core/Src/main.c` is a student template: the I2C temperature read, the conversion of sensor resistance to temperature, and the STOP0 low-power task are marked `TODO (student)`.
