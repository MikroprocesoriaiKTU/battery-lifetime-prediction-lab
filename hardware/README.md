# Hardware

The teaching setup combines two STMicroelectronics evaluation boards with a course-specific sensor/display add-on board. The add-on board is assembled from commercially available modules and through-hole components on an Arduino Uno prototype shield; it is not a custom-fabricated PCB, so there are no PCB layout or Gerber files.

| Folder | Content |
|---|---|
| `schematics/` | KiCad circuit schematic of the add-on board and its connections to the STM32L433 |
| `bom/` | Bill of materials with supplier links, board variants and the workstation parts list |
| `assembly/` | Assembly guide with photographs: building the add-on board, Nucleo jumper settings, stacking and connecting the boards |
